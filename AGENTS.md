# Project Instructions

## Project scope and Unity compatibility
- Work only inside this Unity project.
- Target Unity 6.6.7f1 and use C# features compatible with the installed Unity version.
- Keep Android performance and touch controls in mind when designing or implementing features.

## Preserve project configuration and assets
- Preserve the existing URP, 2D renderer, and Input System configuration unless a change is necessary and approved.
- Do not install packages, change project settings, or access the network without approval.
- Never delete or overwrite existing assets or scenes without asking first.

## Implementation approach
- Make small, focused changes. Implement one feature or system at a time.
- Before implementing a feature, explain which files are expected to change.

## Reporting and verification
- After making changes, summarize the modified files and provide instructions for testing them.
- Do not claim a feature works unless it has actually been tested. State clearly what was and was not tested.

## Git and destructive commands
- Do not commit, reset, revert, or discard Git changes, and do not run destructive commands, without explicit approval.
